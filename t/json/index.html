JSON 格式化

驗證、格式化或壓縮 JSON，錯誤會顯示在畫面上。

本頁工具在瀏覽器本機計算，不上傳檔案、不需要帳號。

JSON 格式化可以幫到誰

從 API、系統紀錄或設定檔拿到一整坨擠在一起的 JSON，貼進來就能排成好讀的縮排格式，有錯也會告訴你。

也能反過來壓縮成一行，常用在工程師除錯、檢查設定檔、整理資料。

為什麼用我們的JSON 格式化

JSON 只在你的瀏覽器裡處理，不會上傳，含金鑰或個資的資料也比較放心。

  • 格式化時可選 2 或 4 個空白縮排
  • 一鍵壓縮成一行
  • 格式錯誤會直接顯示，並可複製或下載結果

JSON 格式化常見問題

資料會上傳嗎？

不會，格式化和驗證都在你的瀏覽器裡進行。

為什麼顯示無法解析？

通常是少了逗號、引號，或用了單引號、結尾多一個逗號，這些在 JSON 裡都不允許。

壓縮會改到資料嗎？

不會，只拿掉空白和換行，內容完全一樣。

可以下載結果嗎？

可以，按「下載」就能存成檔案。
