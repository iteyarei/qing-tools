證件影本加用途字樣

在證件或文件影本上加上「僅供○○用」與日期。只在瀏覽器處理，不會上傳。

本頁工具在瀏覽器本機計算，不上傳檔案、不需要帳號。

證件影本加用途字樣可以幫到誰

交身分證、健保卡、存摺影本給銀行、電信或公司時，先在影本上加一行「僅供○○用」和日期，避免被拿去做別的用途。

常用在開戶、辦門號、租屋、求職或報名活動需要繳交證件影本的時候。

為什麼用我們的證件影本加用途字樣

證件影本只在你的瀏覽器裡處理，不會上傳到任何伺服器，這點對證件最重要。

  • 自動組成「僅供○○用＋日期」，用途和日期都能改
  • 可調字顏色、透明度，位置有斜向、置中、底部
  • 可下載 PNG 或 JPG

證件影本加用途字樣常見問題

證件照片會被上傳嗎？

不會。圖片只留在你的裝置上處理，關掉網頁就沒了。

字要放哪裡比較好？

建議用斜向，字跨過證件主要資料，比較難被裁掉或修掉，但仍看得清楚內容。

支援哪些圖片格式？

支援 JPG、PNG、WebP，單檔 20MB 以內；HEIC 要先轉成 JPG 或 PNG。

加了字樣就一定安全嗎？

可以降低被挪用的機會，但不是絕對保證，還是只交給需要的單位比較好。

同類工具

  • 圖片轉成 PDF — 把 JPG、PNG、WebP 轉成一份 PDF。多張圖合併成單一檔案，只在瀏覽器處理。
  • PDF 轉成圖片 — 把 PDF 轉成 JPG 或 PNG。多頁會打包成 ZIP，只在瀏覽器處理。
  • PDF 合併拆頁 — 把多個 PDF 合成一個，或把一個 PDF 拆頁、刪頁、調整頁序後下載。可以拖曳排順序，手機用箭頭按鈕。只在瀏覽器處理，不會上傳。
  • 發文前把臉車牌打碼 — 選一張照片，自己框出要打碼的臉或車牌，做成馬賽克或模糊後下載。不會自動辨識，也不會上傳。
  • 證件照製作大師 — 把證件照裁成台灣常見的 1 吋或 2 吋尺寸後下載。不會自動去背，也不會上傳。
  • 照片拼一張 — 把多張照片拼成一張：2、3、4、6、9 格拼貼，或把長截圖由上往下接成一張（寬度自動對齊）。可調間距、邊框顏色和圓角，拖曳換順序，下載 JPG 或 PNG。只在瀏覽器處理，不會上傳。
