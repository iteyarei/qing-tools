CSV／JSON 表格資料轉換

把表格（CSV）與資料清單（JSON）互相轉換。可選本機檔案，只在瀏覽器讀取。

本頁工具在瀏覽器本機計算，不上傳檔案、不需要帳號。

CSV／JSON 轉換可以幫到誰

手上有一份 Excel 匯出的 CSV 表格要交給程式或 API 用，或是拿到 JSON 資料想打開成表格看時，貼上或選檔就能互相轉換。

常用在整理名單、匯入匯出系統資料、工程師準備測試資料。

為什麼用我們的CSV／JSON 轉換

本機檔案只在瀏覽器裡讀取，不會上傳。

  • CSV → JSON、JSON → CSV 雙向轉換
  • 第一列當表頭，每列變成一筆資料
  • 結果可複製或下載

CSV／JSON 轉換常見問題

檔案會上傳嗎？

不會，選擇的檔案只在你的瀏覽器裡讀取。

CSV 第一列一定要是欄位名稱嗎？

是的，第一列會當成表頭，其他列依表頭變成一筆筆資料。

JSON 要長什麼樣子？

需要是物件陣列，例如 [{"name":"小明"}]，單一物件也可以。

儲存格裡有逗號怎麼辦？

用雙引號把那格包起來就可以，引號沒結束會提示錯誤。
